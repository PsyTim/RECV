🔑 Токен доступа

Установить локально (файл token.txt)
Токен хранится в файле рядом с app.py. Только печатные ASCII: латиница, цифры, - _ . ~. Минимум 8 символов.
Установить через Render API
Записывает LOGS_TOKEN в env-переменные сервиса и запускает деплой (30–60 сек). Требует env-переменные RENDER_API_KEY и RENDER_SERVICE_ID.

📞 Телефонный номер

Номер будет храниться в памяти сервера и выдан один раз в ответ на запрос с action: ["getNumber"], после чего будет стёрт.
Установить номер
Например: +79991234567. Оставьте пустым, чтобы просто стереть текущий.

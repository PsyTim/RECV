🔑 Токен доступа

Установить локально (файл token.txt)
Простой способ. Токен хранится в файле рядом с app.py. На бесплатном Render пропадёт после пересборки/засыпания сервиса.
Установить через Render API
Токен будет записан в env-переменную LOGS_TOKEN сервиса на Render, после чего сервис перезапустится (30–60 сек). Требует наличия env-переменных RENDER_API_KEY и RENDER_SERVICE_ID.
